# File Header Template

## Required Header Format

All source files must use the following header template:

```
//
// {projectName}
// {fileName.extension}
//
// Short description
//
// Created by Dyego Vieira de Paula on {older_date_between_created_filesystem_or_first_commit}
// Built with AI-assisted development via Cursor IDE
//
```

## Template Variables

- `{projectName}` - The project name (e.g., "PolyhedronismeSwift")
- `{fileName.extension}` - The actual filename with extension (e.g., "Polyhedron.swift")
- `{older_date_between_created_filesystem_or_first_commit}` - Use the older date between:
  - File system creation date
  - First git commit date for the file
  - Format: e.g., "2025-11-04"

## Short Description

The short description should be a concise one-line explanation of the file's purpose.

## Example

```
//
// PolyhedronismeSwift
// Polyhedron.swift
//
// Core polyhedron data structure and operations
//
// Created by Dyego Vieira de Paula on 2025-11-04
// Built with AI-assisted development via Cursor IDE
//
```
